## Deployment interpretation and audit findings

- Configure Vercel production web variables in the **Production** environment before the build. Every `NEXT_PUBLIC_*` value is public and build-coupled; changing it requires a new web build/deployment. No checked-in Vercel configuration supplies the production API or canonical web origin.
- Deploy the Express API separately from Next.js. Its `PORT`, `SUPABASE_ANON_KEY`, and Replit connector context belong to that API host. The production web API base must point at its own authoritative HTTPS origin. The web/API cross-origin route and hosting-port setup must be verified against the actual deployed hosts; no live CORS or host setting was inspected.
- Auth alignment is a hard gate: the web Supabase URL/anon key, the API's bearer-verification anon key and JWT issuer, and the Supabase project attached to Replit Connectors must resolve to the same project and user identity. `SUPABASE_ANON_KEY` is the public anonymous key, not a substitute for `SUPABASE_SERVICE_ROLE_KEY`.
- `DATABASE_URL` belongs to the shared Drizzle library/tooling. The checked API data path proxies through Replit Connectors; package presence alone does not make `DATABASE_URL` a web or API production requirement.
- No first-party OpenAI or Stripe environment reads were found. The web coaching and Player DNA endpoints still return `501`/“coming soon” placeholders rather than invoking OpenAI (`artifacts/postround-web/src/app/api/coaching/route.ts:4–35`; `artifacts/postround-web/src/app/api/player-dna/route.ts:4–29`). The API Story Engine derives creator-story candidates and drafts from stored round evidence without a model dependency (`artifacts/api-server/src/lib/story-engine.ts:125–130,223–261`). Billing displays recorded subscription fields and explicitly offers no plan change or purchase (`artifacts/postround-web/src/app/(dashboard)/dashboard/billing/page.tsx:14–20,24–26,65–75`; `artifacts/postround-web/src/lib/subscription/server.ts:4–16`). The `stripe-replit-sync` workspace reference is only a pnpm release-age exclusion, not an application integration (`pnpm-workspace.yaml:30–41`). Do not add OpenAI/Stripe keys as prerequisites for features not implemented here.
- The inventory covers first-party app/runtime code, framework/build and package scripts, tests, shared libraries, workspace/hosting metadata, and the indirect environment fallbacks read by the Replit Connectors SDK used by the API. Unrelated/generated dependency internals and output, attached assets, and actual `.env` files were excluded. No credential or secret values were inspected; no external services, builds, tests, scripts, or SQL were run, and no application/config source files were changed.

## Configuration beyond environment variables

Supabase Auth Site URL/redirect allowlist, email/OTP delivery and templates, database RLS/grants, Vercel project/root/output/branch/domain settings, API connector authorization, canonical DNS/TLS and optional mobile app identities are manual platform configuration, not invented env names. Their consumers, evidence and release gates are in runbook sections 1, 3–5. Historic upload `${EXPO_PUBLIC_DOMAIN}` is an unresolved mobile API template, not an active first-party env read; no native app is present. Actual local env values are deliberately not audited.

## OpenAI production configuration

No implemented first-party OpenAI key, model or client was found. Web coaching/Player DNA return 501. The external Supabase regeneration function may have a provider, but its code/configuration is absent. Its owner must verify any production provider project/key/budget separately on that service; do not invent a web key setting.

## Stripe production configuration

No implemented publishable/secret/webhook key consumer, product/price ID, checkout, portal or webhook route was found. Stored subscription display is not payment processing. There is no source-selected test/live Stripe mode and no Stripe variable belongs in this template. External/mobile billing remains unverified; do not configure fake production prices, credits or webhook endpoints.
