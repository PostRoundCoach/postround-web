---
name: Creator fixture scope
description: Defines which creator fixtures count for production verification.
---

Only production fixtures explicitly designated for the active creator account count toward creator-content verification. Do not access or reproduce a separately owned test-account fixture merely because it appears in the same data set.

**Why:** Separate test creator accounts intentionally isolate ownership and are not interchangeable with the production creator under verification.

**How to apply:** Confirm fixture ownership and stated scope before authenticated production checks. Exclude separately owned test fixtures unless the user explicitly includes them.
