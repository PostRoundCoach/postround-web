I am preparing to move the Post Round web project from development/preview infrastructure to production.

I will perform the actual production deployment myself. **Do not connect to, modify, or deploy anything to the production environment.**

### Important context

The web project contains **SQL files that are part of the production deployment**.

Do NOT assume that all database work lives in the separate database project.

You must inspect the web project for SQL files, database migrations, RPCs, functions, triggers, policies, seed data, or other database-related deployment artifacts.

Do not delete, ignore, or move these files without documenting why.

The goal is to produce a clear picture of:

1. What belongs in the production web deployment.
2. What environment variables/configuration must change.
3. Which SQL files in the web project must be deployed.
4. Which existing development/preview references must be replaced.
5. Exactly how I should perform and verify the production web deployment.
