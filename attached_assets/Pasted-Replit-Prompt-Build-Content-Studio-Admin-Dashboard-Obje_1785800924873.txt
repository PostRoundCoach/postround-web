Replit Prompt: Build Content Studio Admin Dashboard
Objective

Create a secure internal Admin Portal within the PostRound Coach website (Next.js) that displays AI-generated content ideas stored in the Supabase content_ideas table.

This is an internal tool only. It is not part of the public website and should not be indexed by search engines.

The first module of the Admin Portal is Content Studio.

Future modules (Users, Analytics, AI Usage, Subscriptions, etc.) will be added later, so design the structure to be easily expandable.

Success Criteria

The completed feature should allow an authenticated administrator to:

View all generated content ideas from Supabase.
Filter, search, and paginate through ideas.
Copy hooks and scripts to the clipboard.
Update the status of ideas (Draft, Published, Archived).
Delete ideas with confirmation.
Regenerate an individual idea using the existing Edge Function.
Navigate within a reusable admin layout that can support future business tools.

Important: This should remain an internal admin tool. It must not affect any public-facing pages or the golfer experience in the mobile app. The implementation should prioritize clean architecture, maintainability, and extensibility so the Admin Portal can become the central operational dashboard for PostRound Coach as the business grows.
