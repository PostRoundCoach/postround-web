## Task: Audit Creator Dashboard Data Sources and Supabase Schema

Do **not modify production behavior, database schema, APIs, or UI** as part of this task.

I want a complete audit of the **current Creator Dashboard** and the data it actually displays, with the specific goal of understanding:

1. What information the Creator Dashboard currently receives from Supabase.
2. Which Supabase tables, views, joins, RPCs, API endpoints, and computed fields provide that information.
3. What underlying database fields are available to the Creator Content/Story Engine.
4. Which useful fields exist in Supabase but are currently NOT being surfaced to the dashboard.
5. How we should expose the relevant schema/data to the Creator Content Engine prompt so the AI knows exactly what factual information it can use when deciding what content a creator could make.

This is an **audit only**. Do not refactor or change implementation unless absolutely necessary to inspect the data.
