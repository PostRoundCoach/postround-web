# 8. Distinguish Raw Facts vs Derived Facts

For every important field, classify it as:

### RAW

Directly stored in Supabase.

### DERIVED

Calculated from raw database fields.

### AI-GENERATED

Produced by an AI process.

### UNAVAILABLE

Not currently available to the engine.

This distinction is important because the Creator Content Engine should know what it is allowed to claim as factual.

For example:

`score = 33` → RAW

`score_to_par = -1` → DERIVED from score and par

`"personal breakthrough"` → should NOT be treated as factual unless there is supporting data
