   - `NEXT_PUBLIC_POSTROUND_API_BASE_URL`

   - `NEXT_PUBLIC_SUPABASE_URL`
2. Identify the exact value each variable controls and every place it is used.
3. Trace the actual HTTP requests made by the Creator Studio page and modal.
4. Identify the full endpoint paths, HTTP methods, request parameters, and expected response shapes.
5. Determine whether requests go to `https://api.postroundcoach.com`, a Replit web hostname, Supabase directly, or another service.
6. Inspect the deployed Preview build's configuration and request behavior. Do not assume the current environment-variable settings prove what was embedded in the browser bundle.

## Investigation B: Trace Creator Story retrieval

Follow the exact content idea ID above through the full execution path:

1. Locate the creator dashboard's API endpoint and backend handler.
2. Identify the Supabase project used by the production API, without exposing credentials.
3. Inspect the query, joins, creator ownership filters, permissions, status filters, and row-level security.
4. Establish whether the handler queries `content_ideas` or a different creator-facing output table.
5. Determine whether `draft` content is intentionally hidden or accidentally excluded.
6. Follow the API response into the frontend and identify any additional filtering or rendering conditions.
7. Establish the precise point where this eligible record is lost.

## Investigation C: Trace the Studio follower count

1. Find the component responsible for displaying the follower count.
2. Identify the endpoint or Supabase query that supplies the count.
3. Trace the request to the API handler or database query.
4. Establish how the creator ID is determined and how the count is calculated.
5. Check for stale client state, caching, incorrect response-field mapping, incorrect creator association, authorization filters, and errors silently swallowed by the frontend.
6. Compare the actual response with the count stored in the production database.

Do not assume the follower count and Creator Story failures share a cause. Establish whether their requests use the same API service, configuration, or failing dependency.
